# 鹰眼 · 热气球标志袋视觉裁判系统

无人机在目标区上空拍照 → 用地面目标十字与控制点把照片校正为正射图 →
识别各种颜色的标志袋及其飘带、按颜色 + 编号确认选手身份、分开紧贴的相近色袋子 →
计算袋心到目标十字的距离 → 按比赛规则计分排名并发布成绩。

**TypeScript + React 18 + Vite + Canvas + Web Worker**，零重型第三方视觉依赖；
样例赛场、40 个标志袋、控制点、裁判复核数据以及清晨/正午/傍晚/阴天与
农田垄沟 / 泥地 / 水沟等光线地形样例图全部由程序生成。

## 运行

```bash
npm install
npm run dev        # 打开终端提示的 http://127.0.0.1:5188
```

生产构建与预览：

```bash
npm run build      # tsc 类型检查 + vite 打包（Worker 独立分包）
npm run preview
```

### 命令行精度/性能自测（Node，不依赖浏览器）

```bash
npm run selftest                 # 跑全部 6 个样例
npx tsx scripts/selftest.ts mixed_morning
```

会生成校正/叠加调试图到 `.selftest/<preset>/`。最近一次结果（6 个样例一致）：

- **40/40 全部检出，40/40 身份（编号）正确**；
- 与裁判独立卷尺读数相比：**平均偏差约 0.6 cm，最大偏差约 1.5–2.2 cm，全部 ≤ 2 cm**；
- Worker 同款识别管线在 Node 约 **0.5–0.8 s**，浏览器实测 40 人 **0.72 s**（60 s 预算的约 1.2%）。

> 裁判数据在真值距离上加入了 σ≈0.4 cm 的真实量测误差并记录到厘米，因此“系统 vs 裁判”
> 的厘米级偏差是真实比对结果，而不是直接读取真值。识别器运行时**不读取** `bags` 真值与裁判数据。

## 四个页面

1. **航拍导入**：6 种实时光线/地形样例卡片；一键生成 3600×2700 模拟航拍原片；
   也可上传自己的 JPG/PNG，手动点选控制点。附 40 人颜色/编号名册。
2. **控制点校正**：照片上拖拽 GCP/目标十字，右侧编辑场地米坐标，实时显示各点残差与
   RMSE（样例≈0 cm）；DLT + Hartley 归一化最小二乘解单应，双线性重采样出 40 px/m 正射图。
3. **标志袋识别**：计算全部在 Web Worker 中完成；KPI 显示 40/40、耗时与 60 秒预算；
   Canvas 叠加轮廓、飘带骨架、袋心—十字连线与编号；右侧清单与画布点选联动，
   并标注“紧贴拆分 / 飘带根部 / 区外”。
4. **成绩发布**：规则参数（目标区半径、满分、每米扣分、区内保底、区外最低分）可调并即时重算；
   领奖台、全部袋—十字连线总图、排名表、裁判复核偏差徽标；导出 CSV、打印/PDF、裁判长锁定发布。

## 关键算法（`src/core`，与 DOM 无关，Worker 与 Node 自测共用）

- `geometry.ts`：DLT 单应（≥4 点，多点最小二乘）、矩阵求逆、重投影残差、双线性 warp。
- `scene.ts` / `raster.ts` / `rng.ts`：确定性生成地形（分形噪声、作物垄、泥斑、水沟）、
  光线分级（冷暖/暗角/颗粒/投影）、袋子、飘带、5×7 点阵编号、GCP、目标十字与模拟相机透视。
- `detect.ts` + `vision.ts` + `ocr.ts` + `assign.ts`：
  - HSV 选手色分割与颜色概率图；
  - 高对比编号面板检测、亚像素矩形/圆盘中心拟合、径向轮廓、飘带脊线跟踪；
  - 5×7 点阵 OCR（尺度×平移搜索）；
  - **高置信 OCR 先锁定 + 匈牙利全局最优唯一分配**，颜色仅作权重，
    从而把两个颜色相近但编号不同的紧贴袋正确分开；
  - 在同一正射像素帧内检测目标红心并以此为测距原点，抵消半像素/坐标原点约定误差，达到亚厘米级。
- `scoring.ts`：区内距离线性扣分、区外最低分、距离升序排名、厘米级复核统计。

## 刻意考点

- 3、19、27 号落在两垄庄稼之间，袋体被作物覆盖，仅靠飘带与根部编号定位；
- 7（大红）/23（橙红）、12（蓝）/31（靛蓝）两对颜色相近且袋心相距约 0.85 m，靠编号分开；
- 9、14、33 号飘带斜搭遮住半袋；2、16、25 号在泥地，11、38 号在水沟/沟沿；
- 4、21、29、36、40 号在目标区外，按规则记最低分并排到榜尾。
